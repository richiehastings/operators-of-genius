# Operators of Genius

A comparative framework for types of human genius, by Richard Hastings.

**Thesis.** Physics runs neutrally through every medium; each art form is a translator of a common dynamic, and cognition is where physics becomes experience. Each type of genius is described by one generative **operator**, stated in the same four terms (domain, participants, operator, closure), so that different translators of the same dynamic can be compared formally rather than by impression. The hypotheses are the author's; the analyses test them against the works and the existing literature.
