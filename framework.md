# The operator grammar

Each type of genius is described by one generative operator, stated in the same four terms so different figures can be compared formally rather than by impression. The series so far covers Mozart, Beethoven (with Van Gogh as a second case) and Shakespeare.

| Term | Meaning |
| --- | --- |
| Domain (D) | The bounded space the work happens in: a form, a tonal frame, a stage |
| Participants (P) | The agents inside it: themes paired with instruments, characters, affects |
| Operator (C) | How participants act on each other: exchange, compression, opposition |
| Closure | The condition under which the work may end, and what kind of ending it produces |

The framework draws on physics as structure, not metaphor: equilibrium (Mozart), phase transition (Beethoven), complementarity and conservation (Shakespeare).
